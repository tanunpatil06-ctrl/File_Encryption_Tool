🔐  File Encryption Tool

A modern and secure file encryption & decryption web app built using **Python, Streamlit, and Cryptography (Fernet/AES)**.

This tool allows users to securely encrypt and decrypt files using a password-based key system with a clean and professional UI.

🚀 Features
- 🔓 Secure Decryption with password
- 📂 Multiple File Upload Support
- 🔑 Password Strength Indicator
- ⚡ Strong Password Generator
- 📊 Analytics Dashboard (Encryption/Decryption count)
- 📜 Activity History Tracking
- 📥 Download Encrypted/Decrypted Files
- 🎨 Professional Dark UI (Custom CSS)
- ⚠️ Error Handling for Wrong Password

 🛠️ Tech Stack

- Python 
- Streamlit 
- Cryptography
- HTML + CSS
